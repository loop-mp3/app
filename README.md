# loop/app

The Electron desktop app for [loop](https://loop.mizucode.qzz.io). It opens YouTube Music and loads the Loop extension as part of the app shell.

to download all the prereleases and the the non production builds goto the [releases](https://github.com/loop-mp3/app/releases) page or if you want the latest build just hit up on [installation](https://loop.mizucode.qzz.io/app) page (windows only if you use linux you must be used to compile your stuff yourslef i belive in you)

The extension source lives in `extention/loop`. A GitHub Actions workflow keeps it synced from [loop-mp3/loop](https://github.com/loop-mp3/loop).
